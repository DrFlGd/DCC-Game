# Enemy sprite sheets

**Status: placeholders.** Everything in this folder except `rat/` and `brute_boss/` is
generated by [`tools/gen_placeholder_sprites.py`](../../../tools/gen_placeholder_sprites.py)
(Pillow, deterministic). They exist so every archetype is readable in playtests; replace
them with real art without changing the data contract below.

- **Contract:** one PNG per enemy at `<sprite_id>/facing_8.png`, a single row of 8 frames
  in the order **E, SE, S, SW, W, NW, N, NE** (see [the asset README](../README.md)).
- **Lookup:** each enemy's `sprite` in [`data/enemies.json`](../../data/enemies.json) is an
  id in the top-level `sprite_sheets` table (or a direct `res://` path). The table gives
  the source `frame` size and the in-world `render` size; the renderer scales with
  nearest-neighbour filtering.
- **Rat family** (`spitting_rat`, `hulking_rat`, `rat_pup`, `nest_mother`) are palette
  swaps of the supplied `rat/` sheet. The others are role silhouettes: charger = shelled
  wedge with a ram horn, zoner = spiked puffball, support = robed bell-bearer, tank =
  boulder body with fists, artillery = bomb-carrier with a sack, boss = hooded warden.
- **Regenerate:** `python3 tools/gen_placeholder_sprites.py` from the repository root,
  then let Godot re-import (`godot --headless --path game --editor --quit`) and commit the
  PNGs with their `.import` files.
