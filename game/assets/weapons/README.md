# Weapons and attack visuals

Future weapons live in this directory as independent per-weapon sheets or effect atlases, e.g. `weapons/<weapon_id>/sprite.png`. Keep them out of the biome and character sheets.

This prototype currently renders projectiles and melee telegraphs procedurally. There are **no finished weapon sprite assets** yet. Later, a weapon record should include its source sheet, orientation/animation frame dimensions, hand attachment point, attack pattern, and status-effect/VFX references.
